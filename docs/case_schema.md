# Case Schema

`EngineeringCase` captures reusable engineering knowledge:

- `case_id`
- `module`
- `task`
- `old_algorithm`
- `new_algorithm`
- `constraints`
- `steps`
- `problems`
- `solutions`
- `validation`
- `final_status`
- `reusable_experience`
- `source_conversation_id`

The schema stores verified outcomes rather than raw chat noise.
